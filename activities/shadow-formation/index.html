What Did We Learn?

  • Light travels in a straight line.
  • An opaque object blocks light.
  • A shadow forms when light is blocked.
  • Transparent objects allow most light through.
  • Translucent objects allow some light through.
  • The shadow can change when distances change.

Scientist Tip

Try changing only one thing at a time. Then observe the screen carefully.
